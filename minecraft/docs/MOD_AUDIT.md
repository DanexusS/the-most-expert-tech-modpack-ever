## Семь модов вне защищённого списка

| Мод | Решение | Причина |
|---|---|---|
| Chloride | Пока оставить | Расширяет графические/производительные настройки; удалять только при подтверждённом конфликте по логам. |
| Lithium | Оставить | Отдельная оптимизация игровой логики для клиента и сервера; не является дублем Sodium. |
| Nolijium | Пока оставить | Оптимизационный мод; удаление без профилирования не обосновано. |
| Reese's Sodium Options | Условный кандидат | Это альтернативный интерфейс настроек Sodium. При конфликте с Sodium Options API первым тестируется отключение Reese's. |
| Sodium/Embeddium Options Mod Compat | Оставить вместе с API | Полезен для интеграции настроек ETF/EMF и других клиентских модов, которые есть в сборке. |
| Sodium/Embeddium Options API | Условно оставить | Нужен для Options Mod Compat, но требуется точное совпадение версий с Sodium и Reese's. |
| Wetland Whimsy | Оставить либо удалить только по дизайнерскому решению | Это контентный мод, а не технический дубль. Удаление из существующего мира требует отдельной проверки блоков и биомов. |

## Практическая рекомендация

Ничего не удалять до получения фактической папки `mods` и `latest.log`. Первый диагностический эксперимент при клиентском краше меню настроек: временно отключить Reese's Sodium Options, не трогая Lithium. Для окончательного решения нужны имена и версии JAR-файлов.
