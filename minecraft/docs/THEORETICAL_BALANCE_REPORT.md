## Assumptions

- This model is a static approximation, not a replacement for an in-game benchmark.
- Armor uses a post-1.9 Java-style approximation and ignores enchantments, effects, critical hits and mod-specific damage bypass.
- TTK assumes the first hit lands at time zero and subsequent hits follow the configured attacks-per-second value.
- Recipe complexity is a relative index: occupied slots + namespace breadth + dependency weight. It is not a time estimate.
