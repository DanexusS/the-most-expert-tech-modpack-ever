## Уникальные сущности

В новых заданиях используется 92 уникальных ID сущностей:

- Cataclysm — 14;
- Mowzie’s Mobs — 10;
- Mutant Monsters — 5;
- Earth Mobs — 12;
- DivineRPG — 23;
- Twilight Forest — 15;
- Ice and Fire — 13.

Боссы требуют одну победу. Повышенные значения используются только для рядовых и повторяемых противников. Все большие боевые нормативы находятся в необязательной главе.
